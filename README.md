**EN** · Customs clearance + AI. I build tools that read supplier invoices and packing lists, propose TARIC tariff codes and verify them against the official EU TARIC - the daily work of a customs agency, automated. Python, TypeScript, n8n/Make, OCR + LLM pipelines, RAG and MCP. Based in Burgos, Spain, looking for a role building AI tools for real operations.

**ES** · Aduanas + IA. Construyo herramientas que leen facturas y packing lists de proveedores, proponen partidas TARIC y las verifican contra el TARIC oficial de la UE: el trabajo diario de una agencia de aduanas, automatizado. Python, TypeScript, n8n/Make, OCR + LLM, RAG y MCP. Desde Burgos, busco un puesto donde construir herramientas de IA para operaciones reales.
